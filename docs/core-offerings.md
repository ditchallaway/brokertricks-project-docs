# Core Offerings & Business Model

## Core Offering
Virtual Drone Photography with property boundary overlay suitable for property listings.

---

## Business Model Canvas

| Canvas Block | Details |
| :--- | :--- |
| **Customer Segments** | Residential & vacant land real estate agents, rural land brokers, and listing marketers needing rapid aerial property boundaries. |
| **Value Proposition** | Instant "drone" photography at a fraction of the cost of a flight crew; eliminates weather delays, airspace restrictions, and editing turnaround. |
| **Channels** | Direct-order web portal, targeted agent outreach, land listing Facebook groups, and real estate marketing forums. |
| **Customer Relationships** | Pure self-service; zero-friction ordering with automated transactional email fulfillment. |
| **Revenue Streams** | MVP: Pay-per-shot flat fee. |
| **Key Resources** | Automated aerial rendering pipeline, parcel boundary data source, CloudPanel/Ubuntu hosting environment. |
| **Key Activities** | 1. Generate eye catching virtual drone images of real estate with accurate parcel boundary lines.<br><br>2. Deliver images to the customer's dashboard. |
| **Key Partnerships** | Parcel boundary data providers, mapping/3D tile providers, SureCart/payment gateways. |
| **Cost Structure** | VPS hosting/compute, mapping/tile data query costs, domain/infrastructure overhead. |
